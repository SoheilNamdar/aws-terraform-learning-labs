# Lab 9 — Amazon S3

This lab is a step-by-step exercise for learning how to manage Amazon S3 with
Terraform.

## Learning objectives

- Configure the Terraform AWS provider
- Create an S3 bucket
- Understand bucket naming requirements
- Configure bucket versioning
- Configure server-side encryption
- Block public access
- Add tags to an S3 bucket
- Inspect Terraform outputs and state
- Verify the bucket with the AWS CLI
- Destroy the resources safely
